# honeypot-dashboard
Python multi-protocol honeypot (HTTP, FTP, SSH, Telnet, SMB, SNMP) with a sci-fi themed web dashboard — live attack feed, captured credentials, per-protocol start/stop, swappable vulnerable banners, and login-protected admin GUI. Built for Windows. honeypot, cybersecurity, python, flask, network-security, nmap, ssh-honeypot, ftp-honeypot.
